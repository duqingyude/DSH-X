### 新增功能

- 外壳换成 Rust 原生程序：Windows 安装包从 90 MB 级降到约 15 MB，双击不再出现一个 Electron 窗口。
- 托盘菜单跟着启动项走：每个启动项一组「打开页面 / 启动 / 停止 / 重启」，一眼能看到哪个在跑。
- 新增原生面板（托盘的「打开面板」）：起停核心、看核心输出、打开管理页、改系统开关与界面语言；中英双语，深浅色跟随系统。
- 安装包界面中英双语，默认跟随系统语言，不再弹语言选择框。
- 核心与外壳分开更新：核心走 npm 包（几 MB），只有外壳变了才需要重新下载安装包。
- 运行 dsh 改用本机 Node（22.18 以上的 22 / 24），不再随包带 node.exe；面板里可以直接指定 Node 路径。

### 体验优化

- 启动后不弹面板、也不弹控制台：核心报出管理页地址就直接用系统浏览器打开；再次双击会打开上次的管理页。
- 关闭面板默认收进托盘，核心继续跑；系统通知的署名显示 DSH-X，不再算到 PowerShell 名下。
- 「提示音」开关真正生效：关掉之后通知不再响。
- 图标统一成看板娘：exe、快捷方式、安装 / 卸载程序、窗口、托盘、favicon 换成同一套。
- 核心意外退出会自动重启；外壳退出时核心立刻跟着退出，不再留下占着端口的孤儿进程。
- 启动项动作失败时提示能照着做（例如「核心没有在运行」而不是「通道未连上」）。

### 问题修复

- 修复「停止核心」后面板仍显示运行中、点按钮提示核心还没连上外壳通道。
- 修复停止核心后无法再启动核心。
- 修复卸载后残留空 core 目录，以及卸载后重装会装回已删除的旧目录。
- 修复日志脚本被浏览器扩展拦掉时整页初始化停住、按钮全失灵。

### 其他变更

- 删除 Electron 外壳与 npm 版（@yyh001/dsh-x）；内嵌浏览器、证书例外、缓存清理随外壳一起移除，看网页请用系统浏览器。
- 安装前请先卸载旧 Electron 版 DSH-X，两者不能共存；数据目录仍共用，设置与已装版本不用重来。
- 打包改用 cargo-packager：NSIS / dmg / AppImage / deb，三平台各自出包。
- 核心 npm 包改名为 @duqingyude/dsh-x-core。

## English

### New Features

- The shell is now a native Rust program: the Windows installer drops from a 90 MB-class download to about 15 MB, and double-clicking no longer opens an Electron window.
- The tray menu follows your launch entries: each entry gets Open page / Start / Stop / Restart, so you can see at a glance what is running.
- A native panel (tray → Open panel) starts and stops the core, shows core output, opens the console and edits system switches and language; bilingual, light and dark follow the system.
- The installer UI is bilingual and follows the system language by default, with no language picker.
- Core and shell update separately: the core ships as an npm package (a few MB), and only a shell change needs a new installer.
- dsh now runs on your own Node (22 or 24, 22.18+), with no bundled node.exe; the panel can point at a specific Node binary.

### Improvements

- A start opens no panel and no console: as soon as the core reports its address the system browser opens; launching again reopens the last console.
- Closing the panel hides it to the tray and keeps the core running; system notifications are attributed to DSH-X instead of PowerShell.
- The sound switch now really works: with it off, notifications stay silent.
- Icons are unified around the mascot: exe, shortcuts, installer and uninstaller, window, tray and favicon all use the same set.
- The core restarts itself after an unexpected exit, and quits immediately when the shell goes away, so no orphan process keeps a port.
- Failed launch-entry actions now say what to do (for example "the core is not running" instead of "channel not connected").

### Bug Fixes

- Fix the panel still showing Running after Stop core, with buttons reporting that the core is not connected.
- Fix the core not being startable again after it was stopped.
- Fix an empty core directory left behind after uninstall, and reinstalling into an old directory that had been deleted.
- Fix the whole page failing to initialise when a browser extension blocks the log script.

### Chores

- Remove the Electron shell and the npm build (@yyh001/dsh-x); the embedded browser, certificate exceptions and cache clearing are gone with it — use the system browser for web pages.
- Uninstall the old Electron build first; the two cannot coexist. The data directory is shared, so settings and installed versions carry over.
- Packaging moves to cargo-packager: NSIS / dmg / AppImage / deb, built per platform.
- The core npm package is renamed to @duqingyude/dsh-x-core.
